# Bookstore UI

React + Vite + TypeScript frontend for the Mission 11-12 bookstore.

## Run frontend in development

From this folder:

npm install
npm run dev

Open:
- http://localhost:5173

## Build frontend

npm run build

## API dependency

This frontend expects the backend API to be running at:
- http://localhost:5015

The Vite dev server proxies all /api requests to that backend URL.

For full project setup and backend startup steps, see:
- ../README.md
